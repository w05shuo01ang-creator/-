## EmojiPackage

- 来源：https://github.com/getActivity/EmojiPackage
- 上游许可证：Apache License 2.0
- 用途：运营人员从本地素材仓库筛选表情图片，经元数据清理、标签批注和微信内容审核后上传到云存储
- 仓库存储策略：MemeCraft Git 仓库不收录 EmojiPackage 原始图片，只保留来源与许可证记录
