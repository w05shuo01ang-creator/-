# AI 生图框架

当前版本已经提供 AI 制作入口、模型选择、提示词、画幅选择、每日次数展示和增加次数入口，但没有启用任何真实模型。用户进入页面时会看到“该功能暂未上线，请期待”，云端生成接口也会拒绝请求，因此不会产生模型费用。

## 架构边界

- 小程序只读取模型公开信息，不保存供应商密钥、接口地址或计费参数。
- `memeApi` 云函数是唯一允许调用模型服务的边界。
- `AI_MODELS_JSON` 只配置可公开的模型名称、说明和支持画幅。
- 真正生成前必须在云端完成配额扣减、输出下载、图片格式检查、内容安全审核和云存储入库。
- 生成结果应先进入用户私密区，审核通过后才能公开。

## 模型配置

默认不设置 `AI_MODELS_JSON`，页面处于未上线状态。接入模型适配器后，可以在 `memeApi` 云函数环境变量中设置：

```text
AI_DAILY_LIMIT=3
AI_MODELS_JSON=[{"id":"image-fast","name":"快速模型","description":"适合快速制作聊天表情","aspectRatios":["1:1","3:4","4:3"]},{"id":"image-quality","name":"精细模型","description":"细节更丰富，生成时间较长","aspectRatios":["1:1","9:16","16:9"]}]
```

约束：

- 每个 `id` 必须唯一，只能包含字母、数字、下划线和连字符。
- 最多公开 12 个模型。
- 每个模型最多配置 5 个画幅，只接受 `1:1`、`3:4`、`4:3`、`9:16`、`16:9`。
- `AI_DAILY_LIMIT` 允许 1 到 20，未设置或无效时为 3。
- 设置 `enabled:false` 可临时隐藏模型。

## 接入真实供应商

在 `cloudfunctions/memeApi/index.js` 的 `generateAiMeme` 中按 `modelId` 映射到服务端适配器。适配器至少应实现统一输入输出：

```js
async function generate({ prompt, aspectRatio, openid }) {
  return { buffer, mimeType, providerRequestId }
}
```

每个供应商的 API Key 使用独立云函数环境变量，例如 `IMAGE_PROVIDER_A_API_KEY`，不要写入 `AI_MODELS_JSON`。同一个供应商的多个模型可以共用一个适配器，只在服务端模型映射中改变上游模型名。

接入完成前不要设置 `AI_MODELS_JSON`，否则页面会显示模型，但生成接口仍会提示“模型服务尚未接入”。

## 次数与增加次数

当前页面展示每日基础次数，服务端已经保留每日用量读取位置。正式生成时必须使用数据库事务先扣减次数，再发起供应商请求；失败时应按可审计规则返还。

“增加次数”入口当前不可用。启用前必须明确采用哪种方式：

- 激励广告：观看完成后由可信回调增加次数，并限制每日领取次数。
- 付费购买：必须确认微信小程序类目和虚拟支付政策是否允许。
- 管理员赠送：建立独立的积分流水集合，记录操作人、原因、数量和时间。

不能由客户端直接提交“增加多少次”，否则用户可以伪造请求无限增加。
